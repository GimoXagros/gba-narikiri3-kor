# v1.3 RC16 실기 재검수

작성 상태: **정확 후보 비공개 실기 확인용**. 이 문서의 준비는 실기 PASS 또는 공개 승인이 아니다.

이번 확인 대상은 새 RC16이며, 이전 `ND3_MENU_OPT_16M.gba`의 결함 보고와 구분한다. ROM 크기는 16,777,216바이트이다. 이름표 접두부까지 수정한 소스 빌드의 SHA-256을 최종 묶음 생성 시 기입한다. 각 검사 폴더의 ROM은 같은 내용이고 SAV만 다르다.

기존 개인 ROM/SAV를 덮어쓰지 않는다. 검사 폴더의 같은 이름 ROM/SAV를 함께 별도 위치에 복사한다. 로더가 저장 파일을 중앙 폴더에 보관한다면 검사마다 서로 다른 ROM/SAV 이름을 짝지어 기존 저장과 충돌하지 않도록 한다. 기기에서 생성된 검수 저장도 원본 검사 폴더와 구분한다. 정상 첫 저장, 기존 중단 검수 저장, 합성 해금/챕터 저장의 역할은 `HARDWARE_RETEST.json`에 기록한다.

## 1. 맵 목록·아이템·도감

`synthetic-menu-review`에서 이어하기 후 출발의 맵 목록을 연다.

- 아래 방향으로 끝까지, 위 방향으로 처음까지 연속 이동한다. 길이가 긴 이름의 마지막 글자·밑줄, 선택/비선택 모양, NEW 표시와 커서가 다른 항목을 덮지 않는지 확인한다.
- 처음/끝에서 추가 입력 시 동작도 확인한다. 맵 목록은 끝에서 멈추는 것이 원래 동작이므로 순환하지 않는다는 이유만으로 오류로 판정하지 않는다.
- 선택 목록을 닫아 원래 화면으로 돌아간 뒤 다시 연다. 글자 잔상·덮임·잘림이 없어야 한다.
- 아이템과 몬스터 도감에서는 위/아래 연속 이동, 처음↔끝 순환, 좌우 페이지 이동, 설명 열기/닫기, 목록 재진입을 확인한다. 입력을 멈췄을 때 항목과 설명이 정상적으로 완성되어야 한다. 일본판과 동일 속도라고 가정하지 않는다.

## 2. 교정 지역명과 긴 임무 제목

이어하기 후 대화를 A로 넘겨 마을의 출발 목록을 연다. 아래 선택 순서는 목록을 처음 연 위치를 기준으로 한다. 선택 후 임무 안내와 편성을 진행하고, 훌리오와 캐로가 포함된 팀으로 출동한다. 단순 목록 표시만 확인하는 것으로 끝내지 않고, 선택 후 임무 화면 제목과 실제 진입 장소가 연결되는지 확인한다. 정상 플레이로 만든 진행 저장은 아니며, PC에서는 이 합성 저장을 콜드 부팅한 뒤 일반 버튼 입력으로 경로를 확인했다.

| 교정 지역명 | 검사 SAV 및 선택 순서 | 합격 조건 |
|---|---|---|
| 시간의 더미 | `synthetic-chapter-07`에서 첫 항목 | 선택명·임무 제목 일치, 보라색 포털이 있는 장소 도착, 글자 손상 없음 |
| 냥인 마을 | `synthetic-chapter-11`에서 아래 1회 | 선택명·임무 제목 일치, 야외 마을에서 캐로의 대화 시작 |
| 총영주 저택 | `synthetic-chapter-11`을 새로 불러와 아래 2회 | 선택명·임무 제목 일치, 저택 내부에서 리드가 등장하는 대화 시작 |
| 불꽃 미궁 | `synthetic-chapter-16`에서 첫 항목 | 선택명·임무 제목 일치, 불꽃 미궁에서 캐로의 대화 시작 |
| 시간의 더미 2 | `synthetic-chapter-17`에서 첫 항목 | 선택명·임무 제목 일치, 석조 내부에서 다른 세계의 훌리오가 등장하고 명찰은 `다른훌리오`로 표시하며 이름표에 일본어 접두부가 남지 않음 |

동적 명찰은 전체 역할명 다른 세계의 훌리오/캐로의 짧은 UI 접두부 `다른`에 기존 이름을 붙이는 방식이다. 일본어가 섞이지 않고 명찰 범위 안에 표시되는지도 확인한다.

각 지역은 임무 화면에서 B로 한 번 취소한 뒤 같은 이름을 다시 선택하여 제목이 복원되는지도 확인한다. 임무 시작 대화까지 도착하면 충분하며, 해당 임무를 끝까지 클리어할 필요는 없다. 다음 지역 검사는 묶음의 손대지 않은 해당 SAV 사본으로 시작한다.

긴 제목은 `synthetic-chapter-02`의 레미 유적 지하1층, `synthetic-chapter-06`의 지하2층, `synthetic-chapter-10`의 지하3층, `synthetic-menu-review`의 최하층 임무 화면에서 확인한다. 제목이 온전한지 확인한 뒤 취소하여 목록으로 돌아가고 다시 같은 임무를 연다. 임무 승인 화면의 그림 제목과 검은 층 안내 화면은 서로 다른 자원이다. 진행상 편성이 필요한 화면에서는 안내에 따라 파티를 선택한다. 임무를 끝까지 완주할 필요는 없다.

## 3. 필드의 갈아입기

`inherited-field-suspend`에서 이어하기하면 필드 시스템 메뉴가 열린다. B로 닫고 R로 훌리오 팀을 고른다(초기 스탄에서 리드→훌리오). A로 팀 명령을 열고 위 방향으로 맨 아래 `갈아입기`를 선택한다. A로 들어가 `갈아입기`→`훌리오`→의상 목록을 차례로 선택한다.

- 필드 버튼의 네 글자와 주변 버튼이 정상인지 확인한다.
- 의상 목록에서 L/R의 `세부 정보 보기`, 상세 화면의 좌우 전환을 확인하고 B로 돌아온다.
- 검사를 선택해 확인 창에서 한 번 취소하고, 다시 선택하여 `예`로 확정한다. 캐릭터가 검사 의상으로 바뀌고 필드로 복귀해야 한다.
- 메뉴를 다시 열어 글자·선택 위치가 정상이며 변경한 의상이 유지되는지 확인한다.

## 4. 저장과 재실행

- `normal-first-save`를 불러와 메뉴에 들어갔다 나온 뒤 게임 내 저장을 한다. 에뮬레이터/로더를 완전히 종료하고 다시 실행하여 방금 저장한 파일이 정상 로드되는지 확인한다. 저장 시점의 시간 숫자가 과거 후보와 같아야 한다는 검사는 아니다.
- 맵 왕복을 실행한 검사 SAV 사본에서도 게임이 허용하는 저장 또는 중단 저장을 한다. 완전히 종료·재실행 후 다시 불러와 위치·파티·의상 상태가 맞는지 확인한다. 정상 저장 결과와 합성 검사 저장의 결과를 구분해 기록한다.
- 세이브스테이트 복원으로 위 저장·재실행 검사를 대신하지 않는다.

## 결과 회신

기기명, 사용 로더와 버전(모르면 미상), 실행한 후보/검사 폴더를 적고 아래 네 줄로 결과를 남기면 된다. 메모리 덤프는 필요하지 않다.

1. 목록 이동·처음/끝·페이지·재진입: 정상 / 문제 / 미실행
2. 교정 지역명 5개와 긴 제목 4개: 정상 / 문제 / 미실행(해당 이름)
3. 필드 갈아입기·취소·변경·복귀: 정상 / 문제 / 미실행
4. 저장·완전 종료·재실행 로드: 정상 / 문제 / 미실행(검사 SAV 종류)

문제가 있으면 화면 이름과 바로 전에 누른 입력, 사용한 검사 폴더를 함께 남긴다. 이번 정확 후보의 실기 재확인은 사용자가 제공한 최종 작업지시의 필수 공개 조건이다. 기존 검수본의 3DS 오류 보고를 이 후보의 통과로 바꾸지 않는다.
