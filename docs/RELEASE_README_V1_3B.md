# 나리키리 던전3 한국어 패치 v1.3b 적용 안내

v1.3b는 일본판 B3TJ 원본에 적용하는 누적 BPS 패치이다. 기존 한국어화를 유지하며 대사, 설명, 목록과 안내문의 공백 표시 폭 및 줄바꿈 처리를 보완한다. 결과 크기는 16,777,216바이트이며 문자열 포인터와 저장 위치를 유지한다.

이 프로젝트는 짜알님의 한국어화 1.1을 계승해 Xagros가 진행한다. 제작자·기여자·로고·글꼴과 도구의 고지는 동봉 CREDITS 및 LICENSE 문서를 따른다.

## 적용 방법

지원 원본은 일본판 B3TJ, 크기 16,777,216바이트, SHA-256 `d083d66b818b1353a449af7f1dd4232b490c254a4107951a3749973d03a0a394`이다.

`ND3_B3TJ_K_v1.3b_FROM_J.bps`를 원본에 한 번 적용한다. 기존 한국어 ROM에 덧씌우거나 구판 IPS를 먼저 적용하지 않는다. 원본 ROM과 기존 저장파일을 보존하고, 별도 폴더에서 적용한다.

ZIP에 포함된 적용기는 Python 3으로 실행할 수 있다.

```powershell
python -X utf8 apply_development.py '일본판.gba' --output 'ND3_B3TJ_K_v1.3b.gba'
```

적용기는 원본·패치·결과의 크기와 SHA-256을 검사하며, 기존 결과 파일을 덮어쓰지 않는다. 다른 BPS 적용기를 이용했다면 결과를 동봉 `manifest.json`의 `target_size`, `target_sha256`과 비교한다.

## 공백과 저장파일

문장 속 공백과 확인된 목록의 공백을 반각 폭으로 표시한다. 페이지·대기 순서, 효과와 조건을 구분하는 줄, 숫자 열 및 이름 정렬에 필요한 공백은 별도로 보존한다. 사용자 이름 저장 영역과 키보드는 변경하지 않는다.

기존 저장은 복사본으로 시험한다. ROM 파일명을 바꿀 때는 사용하는 에뮬레이터의 저장파일 연결 방식도 확인한다. 저장 후 완전 종료와 재실행을 거쳐 로드되는지 확인한다.

ROM·BIOS·개인 저장파일·에뮬레이터·글꼴 바이너리는 배포 ZIP에 포함하지 않는다. 이번 후보의 실기 검수는 사용자의 명시적인 요청에 따라 배포 후 진행한다. 이전 버전의 실기 결과를 v1.3b의 실기 통과로 계산하지 않는다.

최종 후보와 검증 범위는 동봉 `검증_요약.md`, `manifest.json` 및 GitHub Release 기록을 따른다. 전체 게임의 무결점이나 모든 기기·로더의 호환성을 보증하지 않는다.

## 결과 식별

결과 ROM SHA-256은 `957002b13e0b2d669ad93cc6598b50ebd9888455768164c6a9b05d1260955886`, 크기는 16,777,216바이트이다. 누적 BPS SHA-256은 `6fb69802538dc20137d98e1699cb20b87d57676d36ed945a5d8829f50763c546`이다.

두 PC 코어에서 첫 저장과 별도 실행 재로드를 확인했다. 실기 실행은 `NOT_RUN`이며 사용자가 배포 후 검수한다. 패키지 공개·다운로드 재검증 상태는 GitHub Release와 동봉 검증 기록을 따른다.
