# 도감·상점·보상 등 추가 문구

2026-09-09. dev18에서 개별 출력 호출을 확인한 40개 문구를 추가해 현재 선택 UI는 70개다. 이 수를 게임 전체 UI의 분모로 사용하지 않는다.

도감의 능력치/드롭/속성, 의상 능력치 보정/장비, 상점·식재료 상점의 선택 안내와 갈드/합계, 보상의 경험치·돈·참가 등의 화면 문구를 번역했다. tools/adopt_additional_ui.py의 40개 고정 선택만 채택한다. 자동 리터럴 검색에는 이전 r1 값을 오인한 후보도 있었으므로 검색 결과를 빌드 입력으로 사용하지 않는다.

각 원래 r1 리터럴 로드와 실제 1DA8 호출을 확인하고 원본 바이트를 고정했다. 수정은 표시 문자열의 포인터와 새 문자열에 한정된다. 효과·가격·능력치·재료 값은 수정하지 않는다. %4d/%5d/%7d/%8d의 변환 순서와 자릿수, %l의 창 지우기, 줄바꿈과 잠금용 ?????를 보존한다.

dev20의 실제 포맷/렌더러 검사는 기존 UI를 합해 370개다. 새 숫자 필드는 0, 경계 근처 값, 필요한 signed/unsigned 범위를 포함한다. 20셀 상한은 분리 검사에서 사용한 보수적 검토 상한이며, 모든 실제 창의 크기를 증명했다는 뜻이 아니다. 실제 수치 범위와 인접 요소를 포함한 화면 확인이 추가로 필요하다.

정상 입력 확인: mGBA dev18과 VBA Next dev20에서 기본 남성 나리키리사 의상 도감의 ‘능력치 보정’, 공격력·방어력·지력·민첩 100이 줄맞춤되어 표시됨을 확인했다. output/v1.1a-dev18-menu-mgba 및 output/v1.1a-dev20-menu-vba의 costume-modifier-observation.json. 미등록 몬스터 ????는 원래 잠금 상태이며 미번역으로 세지 않는다.

나머지 상점·보상·등록된 몬스터·의상 상세의 새 문구는 실제 화면 검토가 남아 있다. 분리 검사 통과를 전편 검수 완료로 표시하지 않는다.

## 지도 스크롤 안내 추가

dev21에서 DA2E0의 지연 안내 두 분기를 추가했다. 선택 UI 합계는 72개다. 원래 창 너비는 팀 전환 가능 시 23셀, 불가 시 13셀, 각각 한 줄이다. 스크롤/뒤로/팀 전환으로 번역하고 %16g/%1g/%17g/%18g 버튼 그림 인수를 보존했다. 원문 중 뒤로 앞의 국소 가나 전환 12만 제거했다. 포맷 검사는 374개이며 버튼 그림 19종을 한글 캐시 재사용 전후로 확인한 76개 사례도 통과했다.

정상 입력: dev21의 mGBA/VBA Next에서 첫 전투 후 Select로 지도를 열었다. frame 44861의 안내와 45605의 스크롤/팀 전환 후 로이드 선택, 45726의 지도 닫기, 45967의 재진입을 직접 관찰했다. 재진입 안내 이미지는 같은 코어의 최초 지도 이미지와 바이트 동일하다. RAM 변경은 없다. 짧은 안내 분기는 실제 일반 플레이 도달 검증이 남아 있다. `qa/traces/first-battle-map.jsonl`은 dev12의 같은 코어 첫 저장을 입력으로 사용한 713개 프레임 명령이다.
