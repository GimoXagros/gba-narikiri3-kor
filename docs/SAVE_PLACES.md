# 저장 장소 표시

v1.1a-dev24에서 원래 저장 정보 화면의 장소 이름 44개를 번역했다. F1D3DC의 포인터 44개만 선택했고 바로 다음 시험용 항목(F1D48C)은 보존했다. 장소 ID나 진행 상태는 바꾸지 않는다.

실제 소비자는 080D01C4다. 02001D20의 +10 모드가 2이면 +12 장소 ID로 표를 조회하고, 11이면 25번 투혼 콜로세움, 3/10이면 기존 마을 이름을 표시한다. 나머지 모드는 장소 이름 없이 접두어만 출력한다. 마을 표기는 일본판 `ﾐﾅｸﾙ`과 기존 대사에 따라 **미나클 마을**이다.

원래 창은 22칸이며 기존 `저장 장소   ` 접두어가 8칸이다. 채택한 장소 이름과 접두어의 최대 합계는 19칸이다. 레미 유적의 층 구분, 시간의 더미, 전생의 문 등은 원본과 기존 번역 대사를 대조했다. 모든 맵 ID의 정상 도달을 확인했다는 의미는 아니다.

tools/verify_save_places.py는 두 글꼴 모드에서 실제 분기·조회·서식·출력을 실행한다. 44개 던전 ID, 마을 모드 2개, 장소 ID를 무시하는 콜로세움 분기 3개, 빈 장소 모드 9개를 합해 116개 사례다. 원래 창 폭, 반환/스택, 저장 상태 필드, 시험 항목 보존을 검사했다. 시험 상태는 분리 CPU 메모리에만 구성하며 사용자 저장 파일을 편집하지 않는다.

dev24 ROM SHA-256: `927eabf78b5a3a06a2ab367742b77c8a52ded52825c8244530dc5e7dec45b9bb`.

모든 누적 분리 CPU 검사가 통과했다. mGBA와 VBA Next에서 새 게임부터 첫 저장, 새 프로세스 불러오기, 초기 아이템 목록/설명의 8개 화면을 직접 확인했다. 저장 시간은 각각 17733/17728이고 같은 코어의 dev23과 저장 파일이 바이트 동일하다. 이 첫 저장은 마을이므로 새 던전 장소 이름의 정상 저장 화면 검증은 별도로 남아 있다.
