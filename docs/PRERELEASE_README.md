# 나리키리 던전 3 한국어화 v1.1a 프리릴리즈

기존 한국어화 1.1을 계승한 검토용 프리릴리즈입니다. 확장 한글 글꼴과 메뉴, 인물 정보, 대사 오류 수정을 포함합니다. 이번 대사 대조에서는 5,208개 위치를 확인하여 403개 수정 묶음, 425개 대사 위치를 수정했습니다.

100% 완성판 또는 전편 무오류 보증판은 아닙니다. 주요 PC 실행 경로와 모든 확인된 대사의 원본 표시 루틴은 검사했으며, 전 분기와 모든 기기의 완주 검증은 남아 있습니다. 시험용 원작 문구도 대조 목록에 포함됩니다.

## 패치 적용

1. 직접 준비한 **일본판 B3TJ 원본 ROM**을 사용하세요. 기존 한국어화 ROM에 적용하는 추가 패치가 아닙니다.
2. BPS 적용 도구에서 `ND3_B3TJ_K_v1.1a_FROM_J.bps`와 일본판 ROM을 선택해 새 파일로 저장하세요.
3. Python이 설치되어 있다면 압축을 푼 폴더에서 다음 명령으로 원본·패치·결과 해시를 함께 검사할 수 있습니다.

```text
python apply_development.py "일본판.gba" --output "ND3_B3TJ_K_v1.1a.gba"
```

입력 원본은 16 MiB이며 SHA-256은 `d083d66b818b1353a449af7f1dd4232b490c254a4107951a3749973d03a0a394`입니다. 결과 파일은 32 MiB이며 정확한 해시는 `manifest.json`에 있습니다. 기존 출력 파일을 덮어쓰지 않습니다.

## 포함 파일

- BPS 누적 패치와 해시를 검사하는 적용 도구
- 대사 수정 리포트와 원문/수정 전/수정 후 전체 내역
- 원본 코드 실행을 이용한 표시 검사, 저장과 불러오기, 두 PC 코어의 제한된 실행 검증 결과
- 제작자 크레딧 및 사용 도구·폰트 라이선스

ROM, BIOS, 세이브, 에뮬레이터 실행 파일은 포함하지 않습니다. 보관 중인 세이브는 별도로 백업하고, 에뮬레이터에서 불러오기 전에 ROM과 같은 파일명으로 복사하세요. 모든 기존 세이브의 호환성을 보증하지는 않습니다.

오류를 제보할 때는 화면, 진행 위치, 사용 에뮬레이터와 버전, 재현 순서를 함께 알려 주세요.
