# 나리키리 던전 3 한국어화 v1.2

v1.2는 기존 한국어화의 번역과 표기를 보완한 일반 릴리스입니다. 완성도 100%, 모든 분기 완주 또는 전편 무오류를 뜻하지 않습니다.

## 패치 적용

`ND3_B3TJ_K_v1.2_FROM_J.bps`를 직접 준비한 일본판 B3TJ 원본 ROM에 적용하세요. 기존 한국어 ROM에 중복 적용하지 마세요. ZIP에 포함한 안내와 적용 도구를 사용하고 결과 파일은 새 경로에 저장하세요. 일본판 ROM, BIOS, 세이브와 에뮬레이터 실행 파일은 배포물에 포함하지 않습니다.

기존 저장을 사용하려면 먼저 복사본을 백업하세요. 사용자가 OLD 2DS + DSPico + GBARunner3에서 기존 저장을 이어 스탭롤까지 진행했다고 보고했습니다. 사용한 GBARunner3 버전은 제공되지 않았습니다. 이 보고는 새 게임/저장, 전체 분기 또는 다른 기기의 검증 결과가 아닙니다.

## 변경 사항

대사 표현, 고유명사·장소 표기, 아이템 및 몬스터 도감 속성 표기를 보완했습니다. v1.1a 대사 검토 기록의 425개 수정 위치를 유지하고 새 위치 960개와 기존 위치 재수정 12개를 반영해, v1.1a 대비 972개 위치의 대사가 달라졌습니다. 현재 누적 검토 기록은 5,208개 추출 대사 위치 중 1,363개 수정 묶음·1,385개 수정 위치입니다. 마지막 용어 검교정에서는 불일치 후보 250개를 원문과 확인하고 19개 레코드를 보완했으며, 이 수는 972개와 겹치는 부분 집합입니다. 위치 수는 고유 문장 수가 아닙니다. xlsx-4458 「요의 문」은 로이드의 의도된 말버릇으로 사용자 확인에 따라 유지했습니다.

## 실행 확인 범위

mGBA와 VBA-Next에서 신규 게임 첫 저장, 별도 실행 저장 재로드, 메뉴와 아이템 설명을 확인하고 코어마다 4개 화면 캡처를 직접 검토했습니다. 두 코어에서 조작으로 첫 전투 경로를 진행했으며 mGBA에서 타이틀과 스탭롤 화면을 확인했습니다. 같은 정상 입력 경로의 v1.1a 화면과 비교하여 브라운의 장소 대사가 「꿈나무 집에서」에서 「내일로 가든에서」로 바뀐 장면을 직접 확인했습니다. 공개 검증 요약의 결과 ROM 해시와 검사별 범위를 확인하세요.

자동 표시 검사와 제한된 실행 확인은 게임 전체를 자연 진행으로 확인했다는 뜻이 아닙니다. 모든 수정 장면, 분기 및 하드웨어 조합의 정상 진행을 보증하지 않습니다.
