# 캐릭터 도감의 별도 이름과 소개문

2026-09-09. 사용자 확정 인물 표기를 적용하고 일본판 원문으로 확인한 오역을 보완했다. 정상 진행의 전체 도감 검증은 진행 중이다.

## 확정 구조와 수정

표 1C06E0은 24 bytes × 37개이다. CF1AE의 37개 목록 생성, CF304의 index×24 조회, CF458의 네 개 소개 포인터 순회로 경계를 교차 확인했다. +0은 소형 이름, +4/+8/+C/+10은 대형 소개, +14는 캐릭터/해금 ID이다. 목록 번호가 의상 목록의 89개 번호와 같다는 가정은 하지 않는다.

37개 소형 이름을 승인된 인물 표기로 바꾸고, 큰 소개문 42개 항목의 표기와 의미를 보완했다. ‘번거롭고 언니 피부’는 원문의 남을 잘 돌보는 누님 같은 성격을 나타내도록 고쳤다. 민트·스탄·루티·리온·죠니·리드·킬·해롤드·콜레트·젤로스·프레세아 등 사용자가 제공한 이름과 이터니아 표기를 반영했다. 원문의 세계 구원/재생 의미가 빠진 일부 소개도 보완했다.

수정은 선택한 79개의 텍스트 포인터와 새 확장 문자열 10D0000..10D0480에 한정된다. 원래 캐릭터 ID, 해금 조회, 소개 사이 줄바꿈, %k 키 대기는 보존한다. 저장 플래그를 변경하거나 강제로 해금하는 패치가 아니다.

## 검증과 한계

- dev20 SHA-256: d58705206ed02a6133fc64519ab8c77ba8bb241b2475a6ebd13181d067f50d38.
- 실제 CF304→CF4BC→816C와 소형 포맷/렌더러로 두 표시 모드의 37개 잠금/해금 목록, 148개 사례를 검사했다. 목록은 14셀, 번호 포함 최대 이름은 그 안에 들어간다.
- 원래 1660/1640/25CC/14F4/1414를 통해 수정하지 않은 소개까지 148개 대형 필드를 두 모드로 실행했다. 296회 출력, 4032개의 글자 번호·위치, 18열×2행 배치, 글꼴 버퍼 경계를 검사했다. 최장 선택 필드는 23셀로 두 번째 줄을 쓴다.
- 이 분리 CPU 검사에서만 글자 지연을 0으로 설정했다. 게임의 대기·출력 코드는 변경하지 않는다. 실제 해금, 소개문 읽기/넘기기 및 복귀는 정상 입력으로 따로 확인해야 한다.
- 첫 검사는 ASCII 마침표/쉼표를 유럽식 전각 부호로 기대해 실패했다. 원작 변환은 일본식 。/、 슬롯을 사용한다. 검사 기대값을 원래 변환에 맞췄으며, 클라스 F 뒤에는 의도한 점 모양을 직접 지정했다. 이 검사용 기대값 오류를 ROM 결함으로 집계하지 않는다.
