# 첫 잠긴 문과 보물상자 경로

2026-09-12. 첫 임무 완료는 아직 아니다. 정상 중단 저장 재개, 도적 변장, 첫 문 열기, 리필 대사, 복도 전투와 회복, 첫 보물상자 및 중단 저장을 확인했다. 게임 RAM 수정과 즉시 저장 상태 가져오기는 사용하지 않았다.

## dev31

입력은 dev30의 정상 9턴 중단 저장 `551ca18a4d85b9b8d999eeaa8523f39085b2f7456566c094313f697cea987853`이다. mGBA의 41852프레임 버튼 경로, 관찰한 10개 화면과 최종 EEPROM을 다시 실행해 모두 바이트 동일함을 확인했다. 도적 변장 후 문 앞에서 ‘특기로 문을 열까요?’를 수락하면 문이 열리고 리필의 두 대사가 이어진다. 첫 상자에서는 애플 구미를 얻었다.

동일 버튼 시간을 VBA에 적용한 첫 시도는 후반 전투 이후 입력이 달라져 상자와 저장에 도달하지 않았다. 실패 보고서는 보존한다. 37959프레임 뒤에 120프레임을 더 기다리고 같은 남은 버튼 순서를 적용하자 상자 입수·중단 데이터 저장완료·종료 화면에 도달했다. 이 경로도 별도로 재생해 세 화면과 저장이 바이트 동일했다. ROM 수정으로 해결한 게임 오류가 아니라 입력 시점 조정이다.

각 저장을 새 프로세스에 불러와 아이템 화면을 직접 확인했다. 애플 구미 4, 라이프 보틀 1, 파나시아 보틀 5는 같고 양상추는 mGBA 3 / VBA 4였다. 서로 다른 전투 결과를 완전히 같은 저장 상태라고 처리하지 않는다.

`qa/traces/mission-first-chest-dev31.json`, `mission-first-chest-dev31-vba.json`과 `qa/results/dev31-first-chest`가 해당 기록이다. `tools/replay_observed_route.py`는 ROM·코어·저장·입력·화면을 연결하고 같은 코어의 이미지/저장 불일치를 실패로 남긴다. 단순 재생 성공은 화면 관찰 완료가 아니다.

## dev32

글자 교체 수정 후 같은 두 경로를 실행했다. mGBA는 10개 중 9개 화면이 dev31과 바이트 동일했고 전투 아이템 목록 한 장의 차이는 손 커서 애니메이션 95픽셀에 한정됐다. VBA의 상자/저장/종료 세 화면은 모두 기존 관찰 화면과 바이트 동일했다. 엄격한 비교 도구가 남긴 저장 불일치 실패를 삭제하거나 자동 성공으로 바꾸지 않았다.

새 mGBA 저장은 dev31의 같은 코어 저장과 중단 검사값·시간 외 모든 바이트가 같다. 새 VBA 저장은 이전 VBA 저장과 전투 결과 값도 달랐지만, 새 mGBA 저장과는 중단 검사값·시간 외 전체 8192바이트가 같다. 두 저장의 원래 합계 검사값도 유효하다.

| 코어 | 새 중단 저장 SHA-256 | 중단 시간 |
|---|---|---:|
| mGBA | 09d08b67991c59685af4787ab6af4e6f4eedbc9274cf586a2ee43ced2f63632c | 106529 |
| VBA Next | bb3fe8468d68d29b4c7ead1aa831436320da2b859015bb545cda42d3d80cf9cd | 106660 |

중단 블록의 검사값 `+F0C..F0F`와 시간 `+18DC..18DF`만 제외한 전체 상태 SHA-256은 양쪽 모두 `6ecd567d33c57d132afce259f37c0541df88a0739861c836decb034f4ee67987`이다. 비교를 위해 저장 파일 자체를 수정하지 않았다.

각 저장을 새 프로세스에 재로드한 아이템 화면을 직접 확인했다. 양쪽 모두 애플 구미 4 / 양상추 3 / 라이프 보틀 1 / 파나시아 보틀 5다. 정상 요리 메뉴의 ‘주먹밥’, ‘필요한 식재료’, ‘라이스 0’, HP 10% 회복 설명도 확인했다. 선택 시 ‘재료가 부족해요’가 나오고 B로 요리 설명으로 돌아왔다. 요리 성공, 다른 21개 요리의 정상 습득, 효과·재료 소비를 전부 검증한 것은 아니다.

`qa/results/dev32-cache-replacement`에 원래 비교 실패·차이 분석·재로드/요리 관찰을 보존한다. 새 기준 입력은 `qa/traces/mission-first-chest-dev32-{mgba,vba}.json`이다. 첫 임무 완료, 나머지 문과 상자, 정상 제작·도감 해금·후반 함정 설치·분기·엔딩 검수는 계속 필요하다.
