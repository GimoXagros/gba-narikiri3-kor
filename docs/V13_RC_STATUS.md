# v1.3 후보 검증 상태

상태: **v1.3 정식 릴리스용 검증 기록**. 사용자 종합 회신과 제한된 기술 근거를 구분하며, 실제 발행·최종 감사 상태는 릴리스 manifest와 GitHub Release를 따른다.

## 최종 사용자 승인과 공개 범위

2026-10-11 사용자는 비공개 검수05 이후 추가 문제 없음과 GitHub 업데이트를 승인했다. 대상은 직전 제공한 C6 ROM16MiB/SHA `d1d27b49dfeb6bbacb77b2112664efbb679f7f30a89f2cd17a1037d64fef1c4b`와 대화 문맥으로 연결하며 사용자 해시 재측정으로 기록하지 않는다. 최소 사용자 검수 대기는 이 종합 회신으로 해제한다. 기기·로더·개별 항목 결과는 UNKNOWN/NOT_RESTATED이고 에이전트 실기 실행은 NOT_RUN이다. [사용자 검수 기록](HARDWARE_ACCEPTANCE_V1_3.md)에 근거와 한계를 분리했다.

C6 독립 표적 검토는89장 중 strict87통과/2실패, bounded89통과다. 두 strict 실패는 턴종료 뒤 index0의32바이트와 index2의27바이트 이전 타일 잔류로 직접 귀속했다. PNG/OAM/PAL/CHAR는 같고 affine을 포함한 활성 OAM의 전체 텍스처 범위와 1D·2D 두 배치 모두 해당 잔류 주소의 교집합은0이다. 원시 실패를 전체 영상 통과로 바꾸지 않는다. 시스템 비활성 버튼의 자연 경로는 NOT_RUN이며 기존 필드 비활성·클레릭 두 특기 제목 회귀와 구분한다.

최종 소스의 문서·패키징 메타데이터만 갱신하며 ROM/BPS는 검수 C6와 byte-identical이어야 한다. 깨끗한 체크아웃의 재현, 명시적 공개 파일·635개 기존 소스 및 새 문서의 자동 소스 아카이브, 실제 동봉 적용기 검사와 최종 감사 판정은 외부 manifest에 정확한 커밋·파일 해시로 연결한다. 공개 자산은 BPS·사용자 ZIP·외부manifest·SHA256SUMS 네 개이며 ROM/SAV/BIOS/전체 대사집/별도 폰트 바이너리·개인 경로는 넣지 않는다.

실제 최종 감사·발행 상태는 릴리스 manifest와 GitHub Release를 따른다. 아래 실기·발행 대기 문구는 이전 후보/검수 시점의 역사 기록이며 이번 사용자 종합 회신으로 소급 수정하지 않는다. 과거 첫 저장17,767±3 실패, 초기 프레임·전투3,866프레임 차이, C5의 애니메이션 위상 예외와 C6의59바이트 비표시 잔류는 서로 다른 근거로 유지한다. 전편 무오류·모든 기기 호환·모든 과거 시험을 최신 후보에서 재실행했다는 주장은 없다.

## C6 검수 시점의 시스템 메뉴

현재 C6 시스템 메뉴 후보는16,777,216 bytes, SHA-256 `d1d27b49dfeb6bbacb77b2112664efbb679f7f30a89f2cd17a1037d64fef1c4b`이며 누적 JP BPS는525,693 bytes, SHA-256 `772fdb97a075c79a9f2e11202043ce0e0c20305597788fe94256a3280f85c55f`이다. C5에서 시스템 자원0·2·3·4·5·6·7의7개 스트림과 bank4/5 두 참조값만 추가 변경한다. 이전 C5의 필드8개와 특기45·46·48 압축 bytes는 동일하다. 일본판 금색판·장식과 흰 획을 유지하면서 같은 갈색 국소 윤곽을 적용한다.

적목록4의313바이트 LZ는 기존 후퇴5 소유345바이트 슬롯 `E737B8..E73911`에, 후퇴5의272바이트 LZ는 기존 적목록4 소유282바이트 슬롯 `E735F8..E73712`에 저장한다. 28항목 bank 위치·index·실제 컴포넌트별 위치표와 소비 코드는 유지하고 두 pointer값만 교환한다. 은퇴 suffix의 목록 프레임 `E73714..E73738` 36바이트와 새 스트림 뒤의 이전 bytes를 그대로 보존한다. 불변 OPT16에 대한 최종46개 쓰기 계획은 중복이 없고 C5→C6 단계와 byte-identical이어야 한다. C5와1,975바이트, OPT16과6,248바이트 다르며 모든 차이는 명시 범위 안이다.

정확 C6의19,851프레임 첫 저장과 별도 프로세스 콜드 로드·메뉴·아이템 설명은 제한된 PC 확인을 통과했다.17,759±0과 전체 SAV가 C5와 같다. 원래17,767±3 실패는 보존한다. 새7개 실제 선택·취소·재진입과 깨끗한 소스 A/B 재빌드·실제 패키지 검사는 별도 근거에 연결한다. 기존 광범위 시험의 전편 재실행·모든 기기 호환을 주장하지 않는다. 새 후보 실기와 최종 감사 GO는 아직 없다.

총영주 저택 합성 챕터11의 등장 인물 안내는 해롤드로 정정한다. 원본 게임 이벤트·대사 변경은 없고 사용자가 해당 장면을 정상이라고 한 회신만 기록한다. 사진의 기기와 정확 후보는 확인되지 않았으므로 C6 실기 PASS 근거가 아니다. 기존 비공개03/04와 이전 소스·관측 기록은 보존하고 신규05 검수 묶음을 만든다.

## 이전 C5 메뉴 가독성 기록

현재 메뉴 가독성 후보 C5의 16MiB SHA-256은 `9ce7e5f41ac9d40128276dae31bde33e423eb60bff3cc2a4559395786f9d26cb`이다. 기존 C4와 비공개 묶음03는 이전 검수 이력으로 보존한다. 8개 필드 버튼은 흰 획을 그대로 유지한 짙은 갈색 국소 윤곽으로 구분하고, 특기 설정·사용은 흰색 채움과 남색 테두리를 사용한다. 일본판 필드 버튼 자체에는 짙은 글자 윤곽이 없으므로 이번 윤곽은 원래 금색 입체판·장식·크기를 보존한 가독성 보완이다.

새 후보는 필드 자원1·8~14와 정보 자원45·46·48의 11개 그림만 C4 이후에 재압축한다. 실제 컴포넌트별 타일 순서를 읽어 수정하며, 원래 글자 획·필드 글자 영역 밖의 장식·팔레트·위치표·코드·저장 형식과 동적 이름 접두부4바이트는 보존한다. 기존 소유 스트림 안에서만 쓰고 불변 OPT16에 대한 최종37개 쓰기 계획은 서로 겹치지 않는다. 정보47의 빈 그림은 그대로다.

깨끗한 소스 체크아웃 두 곳에서 같은 ROM과 누적 BPS를 재생성했다. 정확 후보의 첫 저장19,851프레임 입력과 별도 콜드 로드·메뉴·아이템 설명을 추가 확인했으며17,759±0과 전체 저장 bytes의 C4 일치를 확인했다. 기존17,767±3 실패는 보존한다. 실제 8개 버튼 선택과 특기 설정·사용 화면은 기존 검수용/합성 SAV를 콜드 로드하고 일반 입력으로 확인한 제한된 PC 근거다. 신규 후보의 실기와 최종 표적 감사 GO는 아직 없다.

## 이전 C4 후보 기록

아래의 명찰 접두부 교정 및 PC 근거는 C4 SHA-256 `54a138aea155d38d6730a36eeb7c480034b0ad8e9ab2d339865f2961af6480a0`를 대상으로 한 이전 기록이다. C5는 해당 변경을 모두 유지하지만, 기존 검증 전편을 새 후보에서 재실행한 것으로 표기하지 않는다.

## 구현 및 바인딩

- 맵 목록 할당 20타일과 목록 전용 왼쪽·상단 위치표를 적용했다. 공용 중앙 정렬 헤더 표는 보존했다.
- 승인 지도 자원 6·11·12·17·20, 마을 좌우 자원 65/80·67/82, 안내 자원 52·53 및 순서 자원 102를 편집 가능한 글자 획으로 생성했다.
- 안내 51·54는 원본 그림 그대로이며 보조 52와 53 수정으로 공용 조합을 교정한다. 순서 102만 수정하고 같은 안내의 103은 보존한다. 논리 항목 수와 물리 그림 수정 수는 다르다.
- 페이지 55/56와 통신 84/85는 정적 소비자 근거만 있고 자연 호출이 미관측이다. 추측 번역하지 않고 현행 bytes를 유지했다. 미사용이 증명되거나 문맥 검수가 통과한 것으로 처리하지 않는다.
- 필드 메뉴는 별도 자원 1을 `갈아입기`로 바꾸고 원래 범용 압축 해제 함수로 연결했다. 자원 4는 동일 픽셀 재압축으로 목록 위치표의 소유 공간을 확보했다. 필드 자원 0·2·3의 마지막 압축 토큰을 각각 1바이트 보정했다.

- 새로 노출된 동적 speaker49/50의 공용 접두부4바이트를 `다른`으로 교정했다. 이름 복사19바이트/버퍼24바이트/코드·포인터·저장·별도 중복 상수는 보존했다. 승인 전체 의미는 다른 세계의 훌리오/캐로이며 UI는 짧은 접두부와 기존 이름을 조합한다.

## 남은 공개 게이트

이전 C2의 필드 의상 변경·취소·복귀, 공유 안내와 캐릭터 목록, 넓은 헤더4개의 실제 도달 자원·VRAM·OAM 검토를 제한된 PC 경로에서 완료했다. 새 후보는 동적 접두부4바이트 밖이 완전히 동일하며 기존 코드·자원·저장 형식에 관한 근거를 그 동일성과 결합한다. 새 후보의 첫 저장·별도 프로세스 콜드 로드·메뉴·아이템 설명은 직접 다시 확인했다. 동적 speaker49/50의 양크기 실제 CPU/글꼴 소비자와 최대5글자 폭은 확인했고, 새 chapter17의 실제 명찰은 `다른훌리오`로 판독된다. speaker50 자연 대화 호출은 재실행하지 않았다. 합성 chapter 저장과 기존 제공 검수용 중단 저장을 정상 진행·실기 증거로 바꾸어 기록하지 않는다. 넓은 헤더 취소·파괴·재진입 수명과 지도5의 선택/임무ID/제목/출발/도입 대화는 이전 C2에서 독립 PASS이며 새 후보의 해당 코드·자원은 그대로다. 과거 첫 저장17735 대17767±3 및 전투3,866프레임 차이의 원시 실패와 잔여 인과를 별도로 보존한다.

새 후보의 최소 실기 재검수와 재현·누적 패치·ZIP 적용 및 공개 금지 파일 검사, 최종 독립 감사 GO 전에는 정식 태그와 공개 릴리스를 만들지 않는다. 사용자가 이전 ROM에서 발견한 맵·명칭 문제는 결함 발견 근거이며 새 후보의 실기 PASS가 아니다. PC 소비자 fixture를 실기나 자연 진행 검증으로 기록하지 않는다.

공개 예정 자산은 `ND3_B3TJ_K_v1.3_FROM_J.bps`, `ND3_Korean_v1.3.zip`, `v1.3-SHA256SUMS.txt`, `v1.3-release-manifest.json`이다. ROM·BIOS·개인 세이브·전체 원문·원본 초안·개인 경로·별도 폰트 바이너리는 공개 자산에 포함하지 않는다. 기존 제작자·로고·라이선스 고지는 유지한다.

최신 제한된 PC 관측과 정확 첫 저장 계약은 [v1.3 검증 요약](FINAL_VALIDATION_V1_3.md)에 기록한다. 원래 첫 저장 FAIL과 개별 영상 차이 인과의 미확정 상태를 함께 보존한다.
