**v1.3b는 아이템·도감 설명과 안내문의 반각 공백·줄바꿈을 보완하고 목록 전환을 최적화한 16MiB 누적 BPS입니다.** 일본판 B3TJ에 한 번 적용합니다. 최종 후보의 CPU·두 PC 코어 검증은 완료했으며, 공개 패키지와 배포 검증은 진행 중입니다.

2026-10-11 사용자는 비공개 검수05의 후속 회신에서 추가 문제 없음과 GitHub 업데이트를 승인했습니다. 기기·로더 버전과 개별 항목 결과는 이번 회신에 다시 제시되지 않아 UNKNOWN으로 기록합니다. 이전 OLD 2DS 환경의 진행 보고와 새 후보의 종합 회신을 구분합니다. 아래 v1.2 자료는 이전 공개 버전 기록입니다.

**v1.2는 번역과 표기를 보완한 일반 릴리스입니다. 100% 완성, 모든 분기 완주 또는 전편 무오류를 보증하지 않습니다.**

대사 용어 및 고유명사 표기, 아이템과 몬스터 도감의 속성 표기를 보완했습니다. 기존 사용자가 지정한 로이드의 말버릇 「요의 문」은 해당 대사에 유지했습니다. [v1.2 릴리스 노트](docs/RELEASE_NOTES_V1_2.md)에서 수정과 확인 범위를 설명합니다.

패치는 일본판 B3TJ 원본에 적용하는 누적 BPS입니다. 기존 한국어 ROM에 적용하지 마세요. ROM·BIOS·개인 세이브와 에뮬레이터 실행 파일은 배포하지 않습니다. 기존 저장을 사용하기 전 별도 복사본을 백업하세요. 사용자가 OLD 2DS + DSPico + GBARunner3에서 기존 저장을 이어 스탭롤까지 진행했다고 보고했습니다. 이는 새 게임, 전 분기 또는 다른 기기의 호환성 검증을 뜻하지 않습니다.

로고는 Xagros가 2026-09-13 제공한 교체 원본이며 변형 없이 사용합니다. 게임과 원본 도안의 권리는 각 권리자에게 있습니다.
