# 나리키리 던전 3 한국어화 — 개발 검토판

2026-09-09. **100% 완성판이 아닙니다. 공개 배포용 릴리즈가 아닙니다.**

짜알님의 한국어 1.1 패치를 계승하여 8×8 소형 한글과 미번역 이름을 보완하는 중간 결과입니다. 원본 게임과 기존 한국어 번역의 권리는 각 제작자에게 있습니다.

## 현재 반영한 작업

- 달무리 8×8 한글 2,350자 출력.
- 화자 89개, 기술 390개, 인물·직업 96개, 아이템 123개, 적 기본 목록 212개 작은 이름 연결.
- 기술명 18개 미번역·손상 수정, 사용자 승인 인물·코스튬 표기 반영.
- 새 게임 기본 이름 훌리오·캐로·드림호 및 원래 5글자 이름칸에서 한글 한 글자를 보존하는 가져오기.
- 별도 소형 출력 경로의 한글 지원, 저장 장소·플레이 시간 및 팀 이름 문구 7곳.

기존 번역을 일괄 재작성한 결과가 아닙니다. 번역 검수와 전체 게임 플레이 검증이 남아 있습니다.

## 적용

Python 3.10 이상에서 이 폴더를 연 뒤 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

    python apply_development.py "일본판원본.gba" --output "ND3_개발검토판.gba"

지원 원본은 16,777,216-byte B3TJ 일본판, SHA-256 `d083d66b818b1353a449af7f1dd4232b490c254a4107951a3749973d03a0a394`입니다. 기존 한국어판에 덧붙이는 패치가 아닙니다. 적용기는 원본·패치·결과 해시를 검사하고 기존 파일을 덮어쓰지 않습니다. 게임 ROM·BIOS·개인 저장은 포함하지 않습니다.

## 확인 범위와 남은 사항

CPU 검사에서 두 소형 출력 경로 각각 2,350자 × 두 모드, 원래 가나·영문·탁점 동작, 이름 2,350자 × 5칸 왕복, 선택한 이름 910개와 UI 포맷 7개를 확인했습니다. mGBA에서 새 게임부터 이름 확정·마을·메뉴·첫 저장 완료, 별도 프로세스 이어하기, 초기 아이템 3개의 목록과 기존 설명 표시를 확인했습니다. 상세 검증 해시는 함께 든 JSON과 작업 폴더의 상태 기록에 있습니다.

아이템·적 이름에는 전작과 일본어 이름이 정확히 일치하는 번역을 참조한 초안이 들어갑니다. 적 선택용 중복 목록 등 별도 경로는 남아 있습니다. 위 910개는 선택한 테이블의 항목 수이며 전체 미번역의 모집단이나 번역률을 뜻하지 않습니다.

한글 입력 후보판과 여러 메뉴·저장 정보·전투·그래픽에 일본어가 남아 있습니다. 이름 입력 후보판은 아직 원래 일본어 배열입니다. 표시 중인 한글 타일이 124종을 넘으면 물음표를 내는 개발 진단 동작이 있습니다. 모든 로더·전투 후 글꼴 수명·희귀 이벤트·엔딩·실기·32MiB 확장 호환성과 전체 저장 호환 검증은 끝나지 않았습니다. 시험 결과를 100% 번역률이나 전편 완주로 해석하지 마십시오.

기존 사용자 이름은 새 기본 이름으로 강제 치환하지 않습니다. 새 ROM은 게임 내 저장을 사용하고, 다른 ROM의 임시저장 상태(savestate)는 사용하지 마십시오. 기존 저장 원본은 보관하고 복사본으로 검토하십시오.

달무리 글꼴은 RanolP/dalmoori-font, Apache-2.0입니다. BPS 적용 도구는 GimoXagros/narikiri2-save-compat의 MIT 도구를 참조했습니다. 동봉 라이선스와 CREDITS를 유지하십시오.
