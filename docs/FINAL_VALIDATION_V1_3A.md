# v1.3a 검증 범위

대상 결과는 16,777,216바이트, SHA-256 `0008712948a3dd570d817bdcb15ec2c3ae3a12bf06d56047882569f091e66968`이다. 이전 후보의 결과를 해시가 다른 새 후보의 실행 결과로 계산하지 않는다. 소스 커밋·패키지 검사·독립 감사의 최종 상태는 공개 manifest에 결합한다.

LF 변경은 문자 저장 공간 안에서 수행하며 기존 문자열을 이동하지 않는다. 74개의 연결 공백도 길이를 유지한다. 페이지·대기 코드는 바꾸지 않지만 표시 행 수가 줄어드는 문장은 실제 화면 진행 시간이 달라질 수 있다. 이름 입력·키보드 정렬 공백은 이 변경 범위가 아니다.

## 가상환경 실행

모두 현재 PC 화면을 조작하지 않는 headless 실행이다. 실기 결과가 아니다. 상태 파일을 다른 ROM에 이식하지 않았으며 입력 세이브는 복사본으로 읽었다.

- **부팅:** 첫 완성 안내 화면은 mGBA 기본 BIOS 대체 동작에서 기준본/최종본 모두 2프레임이다. 첫 180프레임 영상 해시도 같다. 실제 BIOS를 사용한 mGBA에서는 7→6프레임, VBA-next에서는 2→2프레임이다. 작업 중 후보에 있던 추가 3프레임 공백은 없다. 화면 복원 데이터 76,800바이트가 정확히 일치한다.
- **아이템 목록:** 선택한 아이템 122종, 6,136프레임 표본. 사용 중인 슬롯 최대 39/124, 참조되지 않은 슬롯 최소 85개. 이는 할당 여유이며 캐시 적중률이 아니다. 짧은 이동 두 곳은 기준본 대비 각각 +1/-1프레임이었다. 1,800프레임 누름 유지 시 아래 이동 233→232회, 위 이동 215→218회로 달랐다. 같은 속도 또는 모든 목록의 무지연을 주장하지 않는다.
- **몬스터 도감:** 154종, 6,264프레임 표본, 38개 전환 구간과 누름 유지 이동 수가 기준본과 일치했다. 사용 중인 슬롯 최대 28/124였다.
- **메뉴:** 필드 버튼 8개, 시스템 명령 7개의 선택·실행·취소·복귀 화면을 기록했다. 확인한 승리 조건·게임 설정의 오른쪽 넘침과 남은 턴 표시를 검토했다.
- **저장·재로드:** 최종 ROM으로 새 게임을 시작해 정상 입력 21,344프레임 후 저장했다. 완전히 별도 프로세스에서 1,886프레임의 로드·메뉴·아이템 재진입을 수행했다. mGBA와 VBA-next 모두 게임 체크섬 및 기존 전체 상태 계약을 통과했다. 타이머·체크섬을 제외한 저장 상태 해시는 `439a1bf22c6323169984dc9eb24d393a3dcbf5ba16b32aa9524209c699898e56`이다.

저장 타이머 19,428(mGBA), 19,427(VBA-next)은 조정한 새 입력 기록에서 관측한 값이다. 성능 동일성의 근거로 사용하지 않는다. 이전 고정 입력은 줄바꿈 변경 후 다른 메뉴에 들어가 저장 검사에 실패했으며, 이를 삭제하거나 허용 오차를 늘려 통과 처리하지 않았다. 축약한 입력 경로의 상태 한 바이트 불일치도 별도 실패로 남겼다. 실제 화면을 따라 확정한 새 입력만 재현 기록으로 채택했다.

## 남은 범위

이번 후보의 실기 실행은 **NOT_RUN**이다. 사용자가 배포 후 실기 검수를 진행한다고 지정했으므로 공개 조건에서는 **DEFERRED_BY_USER**로 구분한다. 이전 v1.3 실기 회신을 이번 후보의 실기 확인으로 재사용하지 않는다.

전체 게임·전 분기 완주, 모든 동적 이름, 모든 저장 파일·에뮬레이터·실기 호환은 검증하지 않았다. 자원 122개를 분류한 그래픽 검토에서 99개는 정적 유지, 1개는 호출 문맥 확인 보류이며 모든 자원의 자연 화면 실행을 뜻하지 않는다. 통신 경로도 이번 검증 범위 밖이다.

검증 단계는 [kr-patch-qa 고정 표준](https://github.com/gagnonjung/kr-patch-qa/blob/cab74ca62c817e1b4626644d99f254b59796e80d/LOCALIZATION_QA_STANDARD.md)에 따라 소스·정적 바이너리·빌드·읽기·실행으로 구분했다. 이 기록은 전체 표준의 모든 선택 검사를 수행했다는 선언이 아니다.
