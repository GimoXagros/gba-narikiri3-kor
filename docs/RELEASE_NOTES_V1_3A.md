# v1.3a — 반각 공백과 메뉴 가독성

일본판 B3TJ에 직접 적용하는 누적 BPS이다. 결과 ROM은 기존 v1.3과 같은 16,777,216바이트이며 기존 문자열 포인터와 저장 형식을 유지한다.

- 확인된 대화 소비 경로에서 단어 사이 공백의 표시 폭을 12픽셀에서 6픽셀로 줄였다. 일반 문장은 화면 폭에 맞춰 이어지며 명시적인 페이지·대기, 목록, 인물·장소 표시 등은 보존한다. 혼합 소비 경로 561개는 이번 일괄 적용에서 제외했다.
- 확인된 아이템 목록 호출부에만 4픽셀 공백을 적용했다. 저장된 이름 123개는 바꾸지 않았으며, 그중 공백이 있는 83개 이름이 표시 변경 대상이다. 이름 입력·키보드 정렬·다른 목록에 전역 적용하지 않는다.
- 필드·시스템 명령과 남은 턴 표기 등을 포함한 별도 그림 자원 22개를 다듬었다. 버튼 오른쪽 흰 획의 넘침과 숫자 사이 간격을 함께 확인했다.
- 작업 중 후보에 생겼던 안내 화면의 추가 3프레임 공백을 없앴다. 2색 화면을 BIOS BitUnPack으로 복원하며 화면 픽셀은 기준본과 같다.
- 목록용 타일을 화면에서 계속 참조하는 동안 재사용하지 않도록 보호한다. 실제 아이템·도감 목록의 사용량과 재진입을 가상환경에서 검사한다.

정확한 결과 해시와 완료된 검증 범위는 공개 manifest와 [검증 요약](FINAL_VALIDATION_V1_3A.md)을 따른다. 목록 전체가 일본판과 같은 속도라는 의미는 아니다. 실기 검수는 사용자의 요청에 따라 배포 후 진행하며, 이번 후보의 실기 실행 결과로 이전 버전의 기록을 대체하지 않는다.

ROM·BIOS·개인 저장 파일은 공개 자산에 포함하지 않는다. 기존 ROM과 저장은 보존하고 별도 복사본으로 적용·시험한다.
