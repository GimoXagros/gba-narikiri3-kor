# v1.3 후보 검증 상태

상태: **WORK_IN_PROGRESS**, 미발행. 버전·파일명은 1.3으로 활성화했으며 기존 v1.2 공개 자료와 검수 기록은 유지한다.

현재 16MiB 후보 SHA-256은 `54a138aea155d38d6730a36eeb7c480034b0ad8e9ab2d339865f2961af6480a0`이다. 이 해시는 ROM 결과에 대한 기록이며 소스 커밋 자신의 SHA를 포함하는 순환 구조가 아니다. 원본 일본판·기존 IPS·소스만으로 해당 결과와 정상 32MiB 비교본을 생성했다. 독립 검증에서 변경이 필요하면 후보 해시와 관련 검증을 갱신한다.

## 구현 및 바인딩

- 맵 목록 할당 20타일과 목록 전용 왼쪽·상단 위치표를 적용했다. 공용 중앙 정렬 헤더 표는 보존했다.
- 승인 지도 자원 6·11·12·17·20, 마을 좌우 자원 65/80·67/82, 안내 자원 52·53 및 순서 자원 102를 편집 가능한 글자 획으로 생성했다.
- 안내 51·54는 원본 그림 그대로이며 보조 52와 53 수정으로 공용 조합을 교정한다. 순서 102만 수정하고 같은 안내의 103은 보존한다. 논리 항목 수와 물리 그림 수정 수는 다르다.
- 페이지 55/56와 통신 84/85는 정적 소비자 근거만 있고 자연 호출이 미관측이다. 추측 번역하지 않고 현행 bytes를 유지했다. 미사용이 증명되거나 문맥 검수가 통과한 것으로 처리하지 않는다.
- 필드 메뉴는 별도 자원 1을 `갈아입기`로 바꾸고 원래 범용 압축 해제 함수로 연결했다. 자원 4는 동일 픽셀 재압축으로 목록 위치표의 소유 공간을 확보했다. 필드 자원 0·2·3의 마지막 압축 토큰을 각각 1바이트 보정했다.

- 새로 노출된 동적 speaker49/50의 공용 접두부4바이트를 `다른`으로 교정했다. 이름 복사19바이트/버퍼24바이트/코드·포인터·저장·별도 중복 상수는 보존했다. 승인 전체 의미는 다른 세계의 훌리오/캐로이며 UI는 짧은 접두부와 기존 이름을 조합한다.

## 남은 공개 게이트

이전 C2의 필드 의상 변경·취소·복귀, 공유 안내와 캐릭터 목록, 넓은 헤더4개의 실제 도달 자원·VRAM·OAM 검토를 제한된 PC 경로에서 완료했다. 새 후보는 동적 접두부4바이트 밖이 완전히 동일하며 기존 코드·자원·저장 형식에 관한 근거를 그 동일성과 결합한다. 새 후보의 첫 저장·별도 프로세스 콜드 로드·메뉴·아이템 설명은 직접 다시 확인했다. 동적 speaker49/50의 양크기 실제 CPU/글꼴 소비자와 최대5글자 폭은 확인했고, 새 chapter17의 실제 명찰은 `다른훌리오`로 판독된다. speaker50 자연 대화 호출은 재실행하지 않았다. 합성 chapter 저장과 기존 제공 검수용 중단 저장을 정상 진행·실기 증거로 바꾸어 기록하지 않는다. 넓은 헤더 취소·파괴·재진입 수명과 지도5의 선택/임무ID/제목/출발/도입 대화는 이전 C2에서 독립 PASS이며 새 후보의 해당 코드·자원은 그대로다. 과거 첫 저장17735 대17767±3 및 전투3,866프레임 차이의 원시 실패와 잔여 인과를 별도로 보존한다.

새 후보의 최소 실기 재검수와 재현·누적 패치·ZIP 적용 및 공개 금지 파일 검사, 최종 독립 감사 GO 전에는 정식 태그와 공개 릴리스를 만들지 않는다. 사용자가 이전 ROM에서 발견한 맵·명칭 문제는 결함 발견 근거이며 새 후보의 실기 PASS가 아니다. PC 소비자 fixture를 실기나 자연 진행 검증으로 기록하지 않는다.

공개 예정 자산은 `ND3_B3TJ_K_v1.3_FROM_J.bps`, `ND3_Korean_v1.3.zip`, `v1.3-SHA256SUMS.txt`, `v1.3-release-manifest.json`이다. ROM·BIOS·개인 세이브·전체 원문·원본 초안·개인 경로·별도 폰트 바이너리는 공개 자산에 포함하지 않는다. 기존 제작자·로고·라이선스 고지는 유지한다.

최신 제한된 PC 관측과 정확 첫 저장 계약은 [v1.3 검증 요약](FINAL_VALIDATION_V1_3.md)에 기록한다. 원래 첫 저장 FAIL과 개별 영상 차이 인과의 미확정 상태를 함께 보존한다.
