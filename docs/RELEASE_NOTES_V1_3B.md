# v1.3b 변경 내용

v1.3a에서 넓은 공백이나 이른 줄바꿈이 남아 있던 대사·설명·도움말과 확인된 목록 표시를 보완합니다. 일본판 B3TJ에 한 번 적용하는 누적 BPS이며, 결과는 16MiB입니다.

## 표시 폭과 줄바꿈

- 아이템·몬스터 설명, 갈아입기 안내, 임무 조건, 인물 소개 및 확인한 도움말에서 문장 속 공백을 반각 폭으로 표시합니다.
- 일반 문장의 고정 줄바꿈은 실제 표시 폭에 맞게 연결합니다. 다음 글자가 창을 넘으면 다음 줄로 이동하며, 페이지·대기 순서를 유지합니다. 효과와 조건 등 서로 다른 항목을 나누는 줄은 보존합니다.
- 공유 이름은 확인된 표시 경로에서만 임시 변환합니다. 이름 저장 데이터와 입력 키보드는 바꾸지 않으며, 숫자 열·사용자 이름의 정렬 공백은 일반 띄어쓰기와 구분합니다.

## 목록과 저장 공간

한 번의 목록 출력에서 타일 정보를 공유하고 글자 픽셀 처리 비용을 줄입니다. 화면이 참조하는 타일을 보호하며, 사용 가능한 타일이 없을 때의 기존 처리도 유지합니다. 일본판과의 실제 전환 프레임 비교 범위 및 결과는 [검증 범위](FINAL_VALIDATION_V1_3B.md)에 기록합니다.

첫 안내 화면의 원래 그림은 손실 없이 복원합니다. 압축 자료의 실제 소비가 끝난 영역 안에 표시 코드를 배치하며, 원래 문자열 시작·종료 위치와 문자열 포인터, 16,777,216바이트 크기를 유지합니다.

## 적용과 검증

[적용 안내](RELEASE_README_V1_3B.md)에 따라 일본판 원본에 적용합니다. 기존 한국어 ROM에 덧씌우지 않습니다. 기존 ROM과 저장파일을 보존하고 별도 복사본으로 확인합니다.

공개 자산은 BPS·적용기·문서이며 ROM·BIOS·개인 저장파일은 포함하지 않습니다. 실기 검증은 사용자의 요청에 따라 배포 후 진행하며, 이번 후보의 실기 실행은 `NOT_RUN`입니다. 전체 게임·전 분기 또는 모든 기기의 무오류를 보증하지 않습니다.

## 확인한 결과와 미채택 실험

최종 후보에서 소비자 검증 14종, 대사 포맷·폭 검사 14,358건과 변경 대사 픽셀 검사 1,442건을 통과했습니다. mGBA와 VBA-Next에서는 첫 저장까지 21,344프레임의 입력 기록과 별도 실행의 재로드 1,886프레임을 재생했고, 정규화한 저장 내용과 타이머가 일치했습니다. 이는 해당 입력 경로의 결과이며 전체 게임 완주 검증은 아닙니다.

공백 없는 다섯 글자 이상 한글 이름을 별도로 묶는 실험은 최종본에 채택하지 않았습니다. 글자 폭 8픽셀은 유지했지만 실제 목록 전환 프레임은 더 줄지 않았고 공용 호출 경로의 CPU 비용이 증가했기 때문입니다.

최종 후보 실기 실행은 `NOT_RUN`입니다. 공개 패키지·소스 재현·다운로드 재적용과 독립 배포 판정은 별도 기록으로 완료 여부를 확인합니다.
