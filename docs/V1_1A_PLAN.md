# v1.1a 작업 기준

2026-09-09 사용자 요청: 기존 추가 수정의 버전을 v1.1a로 지정한다. PC 환경에서 일본판·한국어 v1.1·v1.1a를 비교하여 확인된 오류를 v1.1a에서 수정한다. 전체 미번역을 조사·번역하고, 추가 번역이 비텍스트 데이터를 바꾸지 않았는지 검증한다. 모든 작업 완료 후 GitHub 업로드와 프리릴리즈까지 진행하도록 명시적으로 승인받았다.

## 완료까지의 확인 범위

1. 실행 경로에서 확인된 텍스트만 채택한다. 검색 후보는 번역 입력으로 바로 넘기지 않는다. 원본 바이트·종료·공유 참조·제어·호출자를 보존하고 원위치 왕복을 확인한다.
2. 큰 글꼴 대사, 작은 UI, 별도 작은 출력, 데이터 표, 이름 입력, 이미지 문자를 구분해 모집단과 미해결 영역을 기록한다.
3. 추가 번역은 참조/코드/테이블 경계, 포맷 인수, 공간, 실제 표시를 확인한다. ROM의 선언한 최종 쓰기 외 바이트 차이를 허용하지 않는다.
4. PC 비교는 같은 의미의 진행 상태에서 일본판·v1.1·v1.1a를 관찰한다. 기존 버전에서 발생하는 결함도 원인과 재현 경로를 확인한 후 수정하며 정상 기능을 임의로 바꾸지 않는다.
5. mGBA와 독립된 두 번째 GBA 에뮬레이터에서 부팅·입력·메뉴·저장/재실행·전투·진행을 확인한다. 한 환경의 성공을 PC 전체 무오류로 표현하지 않는다.
6. 최종 정확한 ROM으로 누적 BPS, 적용 도구, 문서와 라이선스를 생성하고 적용 결과를 재검증한다. 원본/완성 ROM과 개인 저장은 공개하지 않는다.
7. 남은 일본어·대사 손상·기능 결함과 검증 공백이 해소되기 전 100%나 작업 완료를 선언하지 않는다. GitHub 프리릴리즈는 사용자의 '작업이 모두 마무리되면' 조건을 따른다.

버전 명칭은 완료율과 별개이다. 이전 development-12 결과와 검증은 보존하고 v1.1a의 다음 누적 빌드에 이어서 반영한다.
