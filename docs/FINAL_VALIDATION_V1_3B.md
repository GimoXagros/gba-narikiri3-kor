# v1.3b 검증 기록

상태: **검증 진행 중 — 배포 승인 아님**

최종 ROM의 CPU·두 코어 실행 검증을 기록한 작업 문서이다. 공개 패키지·소스 재현·배포 판정은 아직 별도 완료가 필요하다. 이전 후보의 통과 결과를 최종 배포본의 결과로 대신하지 않는다.

## 보존 조건

- 결과 ROM은 16,777,216바이트를 유지한다.
- 기존 문자열의 시작·종료 위치와 확인된 문자열 포인터를 유지한다.
- 페이지·대기 제어, 이름 저장, 키보드 및 정렬용 공백을 일반 문장 공백과 구분한다.
- 일본판·기존 한국어판·원본 저장파일은 보존하며 별도 복사본으로 실행한다.

## 검증 범위와 한계

PC 검증은 현재 데스크톱을 조작하지 않는 별도 실행 환경에서 수행한다. 일반 입력 재생과 CPU 단위 검증, 합성 검수 저장을 사용하는 목록 검증은 서로 구분한다. 합성 저장으로 모든 목록 항목을 확인한 결과는 게임의 자연 해금 과정이나 전체 분기를 검증한 결과가 아니다.

최종 후보가 달라지면 ROM 해시에 결부된 검증을 다시 수행한다. 실기 검수는 배포 후 진행하도록 사용자가 지정했으므로, 이전 버전의 실기 결과를 이번 후보의 통과 근거로 사용하지 않는다. 전체 게임·모든 기기·모든 저장파일의 무오류를 보증하지 않는다.

## 최종 후보의 소비자·대사 검사

ROM SHA-256: `957002b13e0b2d669ad93cc6598b50ebd9888455768164c6a9b05d1260955886`

BPS SHA-256: `6fb69802538dc20137d98e1699cb20b87d57676d36ed945a5d8829f50763c546`

일본판·기존 IPS에서 누적 소스 빌드로 생성한 16,777,216바이트 후보를 직접 검사했다.

- 소비자·자원 검증 14종 통과. 항목 설명, 큰 글씨 이름, 임무 조건, 자막, 동적 이름, 인물 소개, 안내문과 압축 자원 경계를 포함한다.
- 고유 대사 4,786개를 세 가지 사용자 이름 구성으로 검사한 포맷·표시 폭 14,358건 통과.
- 변경된 고유 대사 1,442개를 실제 ARM 렌더러로 실행한 픽셀 비교 통과. 실패 0건.
- 검사 대상 ROM에 코드를 덧씌우지 않았으며 검사 전후 전체 해시와 크기가 일치했다.

직전 후보에서 발견된 124개 타일 슬롯 사용 중 조기 반환 문제는 수정되었다. 독립 검사 기록에서 최종 해시에 대해 슬롯 사용량 118~124개·두 팔레트·경계 이름을 조합한 28건의 픽셀 및 출력 위치 일치를 확인했다. 타일 압박 검사는 일반 소비자 검사와 별도로 수행했다.

CPU 검사는 할당기·DMA·프레임 대기를 모델링한 독립 실행 검사이다. 일반 입력으로 게임을 실행한 검사, 성능 측정, 실기 검수와 동일한 증거로 취급하지 않는다. 임무의 192픽셀 폭과 일반 대사의 216픽셀 폭을 각각 확인하며, 페이지·대기 순서와 사용자 이름의 공백 보존은 별도 조건으로 검사한다.

이 문서의 CPU 검사 완료는 독립 배포 승인·공개 패키지 검증·GitHub 발행 완료를 뜻하지 않는다. 나머지 게이트는 위 표의 상태를 따른다.

## PC 실행 및 부팅 관측

mGBA와 VBA-Next에서 첫 저장까지 21,344프레임의 입력 기록, 별도 프로세스에서 재로드 1,886프레임을 실행했다. 정규화한 저장 내용이 일치했고 타이머 차이는 0이었다. mGBA 첫 저장 화면과 두 코어의 재로드 화면을 직접 확인해 반각 공백과 줄 배치를 검사했다.

mGBA의 초기 180프레임과 입력을 포함한 600프레임, 실제 BIOS를 사용한 초기 180프레임은 비교 기준과 픽셀이 일치했다. VBA-Next에서는 첫 프레임만 달랐다. 기존의 부분 표시 607개 흰 픽셀 대신 검은 화면이 나왔으며, 2~180프레임은 동일하고 표시 시작 시점은 늦어지지 않았다.

일본판과 같은 고정 입력으로 최종 후보의 아이템·도감 목록을 비교한 측정은 `PASS_SCOPED_PERFORMANCE`였다. 아이템 재진입은 일본판과 후보 모두 3프레임, 도감 상세에서 목록 복귀는 모두 25프레임, 도감 재진입은 모두 31프레임이었다. 이 수치는 최종 표시와 같은 텍스트 영역이 안정되는 시점을 측정한 것이다. 합성 검수 저장을 사용한 목록 항목 선택·장시간 이동·상세 전환·재진입의 한정된 결과이며, 모든 장면의 프레임 성능을 보증하지 않는다.

다섯 글자 이상 한글 이름의 별도 일괄 출력 실험은 실제 전환 프레임 이득이 없고 공용 호출의 CPU 비용이 늘어 최종본에 채택하지 않았다. 기존 글자 폭 8픽셀을 유지한다.
