# 나리키리 던전3 한국어 패치 v1.3 적용 안내

v1.3은 일본판 B3TJ에 바로 적용하는 누적 한국어 패치이다. 결과 크기는16MiB이며 기존 번역·표기·메뉴 최적화를 유지하고 맵 목록·그림 표기·메뉴 가독성을 수정한다. 실제 발행 상태와 정확한 소스 커밋·검증 게이트는 동봉 manifest와 GitHub Release를 따른다.

이 프로젝트는 짜알님의 한국어화1.1을 계승해 Xagros가 진행한다. 기존 제작자·기여자·로고·글꼴과 도구 라이선스 고지는 동봉 CREDITS 및 LICENSE 문서를 따른다.

## 적용

일본판 B3TJ 원본(16,777,216 bytes, SHA-256 `d083d66b818b1353a449af7f1dd4232b490c254a4107951a3749973d03a0a394`)에 `ND3_B3TJ_K_v1.3_FROM_J.bps`를 한 번 적용한다. 기존 한국어 ROM에 적용하거나 구판 IPS를 먼저 적용하지 않는다. 개발 빌드에서1.1 IPS를 사용하는 절차와 사용자 BPS 적용은 다르다.

ZIP을 별도 폴더에 풀고 Python3로 동봉 적용기를 실행한다. 원본과 결과 경로는 다르게 지정하고 기존 ROM·세이브 복사본을 보존한다.

```powershell
python -X utf8 apply_development.py '일본판.gba' --output 'ND3_B3TJ_K_v1.3.gba'
```

적용기는 원본·패치·결과의 길이와 SHA-256을 검사하며 기존 결과 파일에 덮어쓰지 않는다. 다른 BPS 적용기를 사용해도 결과는 정확히16,777,216 bytes와 SHA-256 `d1d27b49dfeb6bbacb77b2112664efbb679f7f30a89f2cd17a1037d64fef1c4b`여야 한다. 결과가 다르면 실행하지 않는다.

ROM·BIOS·개인 저장·에뮬레이터·폰트 바이너리는 포함하지 않는다. 새 기기나 로더에서 기존 저장을 시험할 때는 별도 복사본으로 로드·재저장·재시작 후 재로드를 확인한다.

사용자는2026-10-11 비공개 검수05 이후 추가 문제 없음과 GitHub 업데이트를 승인했다. 이번 회신의 기기·로더·개별 항목 결과는 다시 제시되지 않아 UNKNOWN이다. 에이전트의 해당 후보 실기 실행 또는 모든 기기 검증으로 해석하지 않는다.

변경 범위와 남은 한계는 동봉 `검증_요약.md`를 참조한다. 범위 밖 전체 검증 또는 모든 기종 호환을 보증하지 않는다.
