# 나리키리 던전 3 한국어화 — v1.1a 개발 검토판

2026-09-12. **100% 완성판이 아니며, 공개 배포용 릴리즈가 아닙니다.**

짜알님의 한국어 1.1 패치를 허가받아 계승하여 미번역·오역과 글자 표시를 보완하는 중간 결과입니다. 원본 게임과 기존 한국어 번역의 권리는 각 제작자에게 있습니다.

## 반영한 내용

- 달무리 8×8 한글 2350자, 30페이지 이름 입력 후보판과 원래 5글자 이름칸의 한글 처리.
- 화자 89개, 기술 390개, 인물·직업 96개, 아이템 123개, 적 기본 목록 212개의 소형 이름 연결. 사용자 승인 인물·코스튬 표기를 적용합니다.
- 대형 기술명 98곳, 기술 설명 50곳, 아이템 설명 35곳, 대사 244개 항목의 보완. 기존 번역을 임의로 일괄 재작성한 결과는 아닙니다.
- 요리 이름, 인물 소개, 저장 장소, 함정 선택 메뉴 등 확인된 문자열과 일부 전투 안내 그림의 한국어화.
- 인스펙트 아이의 별도 글자 표시와 속성 기호 보완.
- 캐릭터 명감 23~37번의 이름과 초상화·소개 불일치 수정. 일본판과 37명 전원, 이름·소개·출전 185개 필드를 대조하고 한국어로 정리했습니다.
- 최초 한국어 안내 화면의 기존 제작자명 아래에 Xagros를 추가했습니다.
- 글자 저장 공간이 꽉 찼을 때 교체할 셀까지 보호하여 불필요하게 물음표가 나오던 경계 오류 수정.

위 수치는 선택한 필드와 수정 항목 수입니다. 전체 게임 번역률의 분모가 아닙니다. 정확한 결과 ROM과 원본·패치의 해시는 동봉 manifest.json에 기록합니다.

## 적용

Python으로 이 폴더의 적용기를 실행합니다. 별도 패키지 설치는 필요하지 않으며 Windows의 Python 3.14에서 확인했습니다.

    python apply_development.py "일본판원본.gba" --output "ND3_B3TJ_K_v1.1a.gba"

지원 원본은 16,777,216바이트 B3TJ 일본판이며 SHA-256은 `d083d66b818b1353a449af7f1dd4232b490c254a4107951a3749973d03a0a394`입니다. 기존 한국어판에 덧붙이는 패치가 아닙니다. 적용기는 원본·패치·결과 해시를 검사하고 기존 출력 파일을 덮어쓰지 않습니다. ROM·BIOS·개인 저장은 포함하지 않습니다.

## 확인한 범위

현재 결과의 분리 검사 28개가 통과했습니다. 두 소형 출력기의 전체 한글 픽셀, 124칸에서의 교체 경계 16건, 원래 가나·영문·탁점, 이름 입력/확정/삭제, 선택한 데이터의 실제 소비자와 비텍스트 보존을 확인했습니다. 대사 5208개를 이름·배경 6조건으로 출력하고 원래 글꼴 비트와 비교했습니다. 이러한 검사는 각 장면의 의미 검수나 전편 플레이를 대신하지 않습니다.

mGBA와 VBA Next에서 새 게임·첫 저장·새 프로세스 재로드·메뉴/아이템을 확인했습니다. 첫 임무의 도적 변장·첫 문·일부 전투/회복·보물상자·중단 저장 재개와 주먹밥 메뉴의 재료 부족 안내도 확인했습니다. 이번 dev33에서도 두 코어의 새 게임·첫 저장·별도 프로세스 재로드를 확인했습니다. 해금 검토 세이브로 37명의 네 소개 필드와 목록 복귀를 확인하고, 일본판과 37개 초상화가 일치하며 두 코어의 소개 148개 표시가 일치함을 검사했습니다. 정상 해금 과정의 검증과는 별개입니다. 저장·화면·코어의 정확한 연결은 검증 JSON과 작업 저장소의 문서에 보존합니다. 두 코어의 전투 결과와 시간이 항상 같다고 주장하지 않습니다.

## 남은 사항

시스템·그래픽·대사의 전체 모집단 조사와 의미 검수, 본편/서브/희귀/분기/엔딩 확인은 끝나지 않았습니다. 첫 임무 완주, 정상 의상 제작, 추가 요리 성공·해금, 인물 도감 해금, 후반 함정 설치 등도 남아 있습니다.

소형 글자는 124종류를 동시에 유지하는 공간을 사용합니다. 실제로 이 한계를 넘으면 물음표를 내는 개발 진단 동작이 남아 있으며, 모든 화면의 최대 글자 수와 글꼴 재로딩 수명은 검증 중입니다. 모든 사용자 저장, 실기, 32MiB 확장 호환성과 오디오 청취 검증도 완료하지 않았습니다.

게임 내 저장의 복사본으로 검토하고 기존 저장 원본은 보관하십시오. 다른 ROM에서 만든 즉시 저장 상태(savestate)의 호환성은 확인하지 않았습니다. 기존 사용자 이름을 새 기본 이름으로 강제 치환하지 않습니다.

달무리 글꼴은 RanolP/dalmoori-font의 Apache-2.0 자료입니다. BPS 적용 도구는 GimoXagros/narikiri2-save-compat의 MIT 도구를 참조했습니다. 동봉 라이선스와 CREDITS를 유지하십시오.
