# 나리키리 던전 3 한국어 패치 v1.3

v1.3은 일본판 B3TJ 원본에 한 번 적용하는 누적 BPS이며 결과는16MiB이다. 짜알님의 기존 한국어화1.1을 계승한 v1.2의 번역·표기와 Xagros의 교정 내용을 유지한다. 기존 한국어 ROM이나 구판 IPS를 선행 적용한 ROM에 적용하지 않는다.

이번 변경은 실기에서 보고된 맵 목록의 글자 손상, 지역명 그림의 연결, 필드 `갈아입기` 표시를 수정한다. 맵 목록의20타일 그림에 맞게 목록 전용 할당·위치표를 적용하고 공용 중앙 헤더는 보존한다. 시간의 더미·냥인 마을·총영주 저택·불꽃 미궁·시간의 더미2와 긴 임무 제목의 실제 선택·취소·재진입 경로를 확인했다. 다른 세계 인물의 동적 명찰에는 기존 이름 앞에 한글 `다른`을 붙인다.

필드8개와 시스템7개 버튼은 흰 글자 획과 일본판의 금색 입체판·장식·크기를 유지하며 국소 갈색 윤곽을 더한다. 특기 설정·사용 제목은 기존 한글 모양을 흰색으로 채우고 짙은 남색 테두리를 적용했다. 적목록·후퇴의 그림은 검증된 두 기존 압축 슬롯만 교환하며, 목록 프레임과 실제 소비 코드를 보존한다. 총영주 저택 검수 안내의 등장 인물을 해롤드로 바로잡았고 원본 이벤트는 변경하지 않았다.

기존16MiB 배치와 메뉴 성능 최적화는 유지한다. 이전의 한정된 측정에서는 도감 위 방향 연속 입력의 항목 처리량이 일본판보다 약11% 적었으며, 이는 전체 CPU·게임 속도의 차이를 뜻하지 않는다. 일본판과 동일 속도 또는 완전한 영상 동일성을 주장하지 않는다.

깨끗한 소스 빌드와 누적 BPS 재적용은 정확히16,777,216 bytes, SHA-256 `d1d27b49dfeb6bbacb77b2112664efbb679f7f30a89f2cd17a1037d64fef1c4b`를 만든다. 첫 저장과 별도 실행 콜드 로드를 PC에서 확인했고, 사용자는 비공개 검수05 이후 추가 문제 없음과 GitHub 업데이트를 승인했다. 이번 회신의 기기·로더·개별 항목 결과는 다시 제시되지 않아 UNKNOWN으로 기록한다. 개발자가 해당 후보를 실기에서 직접 실행한 것은 아니다.

원래 첫 저장 타이머17,767±3 검사는 실패로 보존한다. 정확한 ROM·코어·입력의 새17,759±0 관측 계약과 정상 저장 내용은 별도로 연결한다. 과거 전투 영상3,866프레임 차이와 초기 프레임 예외, 새 시스템 장면의 strict87통과/2실패·bounded89통과를 전체 영상 통과로 바꾸지 않는다. 두 시스템 실패의59바이트는 화면에서 참조하지 않는 이전 타일 잔류로 검증했다. 시스템 버튼 비활성 상태의 자연 경로, 통신 관련 미관측 경로 등 한계는 검증 요약에 남긴다.

ROM·BIOS·SAV·전체 대사집·별도 폰트 바이너리는 배포하지 않는다. 기존 저장은 백업한 사본으로 시험한다. 전체 게임·모든 분기 완주나 모든 기종 호환을 보증하지 않는다. [적용 안내](RELEASE_README_V1_3.md), [확인 범위](FINAL_VALIDATION_V1_3.md), [사용자 검수 기록](HARDWARE_ACCEPTANCE_V1_3.md), [크레딧](../CREDITS.md)을 참고한다.
